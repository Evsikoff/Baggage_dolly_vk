# Генератор уровней для головоломки с областями

Готовое автономное ядро для поля 7×7. Оно:

- разбивает поле на прямоугольные области площадью от 2 до 12 клеток;
- ставит ровно одну подсказку внутрь каждой области;
- случайно показывает либо только площадь, либо площадь и тип формы;
- решает уровень теми же данными, которые получит игрок;
- пропускает только уровни с единственным решением;
- оценивает интересность и отбрасывает однообразные или слишком очевидные варианты;
- присваивает сложность `tutorial`, `easy`, `medium`, `hard` или `expert`.

## Правила, зафиксированные в генераторе

Область всегда является прямоугольником. Тип формы определяется так:

- `square` — ширина равна высоте;
- `horizontal` — ширина больше высоты;
- `vertical` — высота больше ширины.

Подсказка формы ограничивает только один из этих трех типов. Подсказка площади всегда обязательна. Координаты начинаются с нуля от левого верхнего угла.

## Быстрый запуск

Нужен Python 3.11 или новее. Внешних библиотек нет.

```powershell
python -m levelgen generate --count 20 --seed 42 --output levels.json
```

Сгенерировать уровни определенной сложности:

```powershell
python -m levelgen generate --count 10 --difficulty hard --output hard-levels.json
```

Поднять или опустить порог фильтра интересности:

```powershell
python -m levelgen generate --count 10 --min-interest 58
```

Проверить уже существующий JSON:

```powershell
python -m levelgen analyze levels.json
```

Запустить тесты:

```powershell
python -m unittest discover -s tests -v
```

В каталоге `examples` лежат 25 заранее проверенных уровней: по пять для каждой сложности.

## Формат уровня

```json
{
  "version": 1,
  "width": 7,
  "height": 7,
  "clues": [
    {"x": 0, "y": 1, "area": 6},
    {"x": 4, "y": 0, "area": 4, "shape": "square"}
  ],
  "interestScore": 71.4,
  "difficultyScore": 53.2,
  "difficulty": "medium",
  "solution": [
    {"x": 0, "y": 0, "width": 3, "height": 2}
  ]
}
```

`solution` нужна для проверки завершенного поля и может быть исключена из экспортируемого файла флагом `--without-solution`.

## Как считаются оценки

Фильтр интересности учитывает начальное число допустимых вариантов, долю мгновенно очевидных областей, разнообразие площадей, размеров и форм, смесь двух типов подсказок и число областей. Неуникальные уровни всегда отбрасываются.

Сложность основана на количестве локальных вариантов, объеме поиска решателя, числе точек выбора и доле скрытых подсказок формы. Все исходные признаки и статистика решателя сохраняются в поле `evaluation`, поэтому веса можно калибровать по реальным прохождениям игроков без изменения формата уровня. Текущие пороги — стартовая эвристика; после первых игровых сессий их стоит откалибровать по медианному времени прохождения и числу ошибок.

## Веб-игра в каталоге `dist`

Статическая сборка без зависимостей: `index.html`, `styles.css`, `app.js`,
`luggage.js`, `i18n.js` и уровни из `examples`.

Вёрстка построена на сцене 16:9 размером 1600×900 условных пикселей. Один `rem`
равен сотой доле ширины сцены, поэтому все размеры в стилях заданы в `rem` и
масштабируются вместе с экраном: прокрутка не нужна ни на одном разрешении. На
экранах выше ширины сцена разворачивается в вертикальную раскладку и тоже
занимает ровно один экран.

Когда рейс собран, гружёная тележка с тягачом уезжает вниз за границу кадра,
а на освободившееся место сверху приезжает новая — уже с бирками следующего
уровня. Перрон под ними — отдельный неподвижный слой с фотографией бетона
`apron-ground.jpg` в пропорции стопки 25:34, а сама тележка — PNG, вырезанный
по контуру, поэтому асфальт не уезжает вместе с машинами. При `prefers-reduced-motion: reduce`
смена происходит мгновенно, без проезда.

Все тексты интерфейса лежат в одном файле `dist/i18n.js`: английский, русский,
немецкий, испанский и французский. Язык определяется по настройкам браузера и
переключается в шапке; выбор сохраняется в `localStorage`. Чтобы добавить язык,
допишите его в `LANGUAGES` и скопируйте блок строк в `STRINGS`. Значение строки —
либо текст с подстановками вида `{name}`, либо объект с формами множественного
числа по категориям `Intl.PluralRules`.

Локальный просмотр:

```powershell
python -m http.server 8123 --directory dist
```
